# City Skyline (freeCodeCamp)

Proyecto *Learn CSS Variables by Building a City Skyline*, resuelto completo.

- `index.html` / `styles.css` — el proyecto terminado (paso 115).
- `GUIA-PASOS.md` — los 115 pasos, con el enunciado y el cambio exacto de cada uno.
- `pasos/paso-NNN/` — el código completo tal como queda después de completar el paso NNN.

Para retomar en un paso concreto, copia los dos archivos de la carpeta de ese paso
en el editor de freeCodeCamp.

El diseño responde al ancho de la ventana: por debajo de 1000px la ciudad pasa de
día a noche gracias a la media query del final de `styles.css`.
