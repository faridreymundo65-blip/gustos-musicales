# Flappy Penguin (Learn CSS Transforms by Building a Penguin)

- `GUIA-PASOS.md` — los 104 pasos con el enunciado y el cambio de cada uno.
- `pasos/paso-NNN/` — codigo completo tras completar el paso NNN.

Nota: `pasos/paso-104/` es el estado ANTES del ultimo paso.
Aplica los pasos de uno en uno: varios tests comprueban el estado exacto
de ese paso (cuantas reglas hay, en que orden), asi que adelantarse
rompe los pasos intermedios.
